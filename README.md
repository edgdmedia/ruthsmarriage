# Ruth's Marriage

A 1:1 port of [ruthsmarriage.com](https://www.ruthsmarriage.com) from
WordPress (Hello Elementor + Elementor Pro + JetEngine) to Astro + EmDash CMS
on Cloudflare Workers (D1 + R2). The design stays pixel-identical at
1440/1024/390 — this is not a redesign.

The step-by-step runbook for the migration lives in
[`migration-plan/README.md`](migration-plan/README.md).
