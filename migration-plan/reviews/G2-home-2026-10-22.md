## Punch list (in order)

1. **No web fonts load at all (root cause).** `src/styles/tokens.css` puts its `@import "@fontsource/…"` lines at line ~39, **after other rules**. Browsers drop an `@import` that isn't at the top of the stylesheet, so no `@font-face` is registered (`document.fonts` is empty) and everything renders in Arial/Helvetica. Fix: move the seven `@import`s to the very top of the file (or import the `@fontsource` CSS from `Base.astro`/`Canvas.astro` frontmatter). Verify with the comparer's "Fonts loaded" line, which must list Nunito, Poppins and Roboto. (All three `@fontsource` packages are installed; only the import placement is wrong: `:root {` starts at line 5, the imports at line 39.)
2. **Header nav** (`_global.md` → Desktop nav items): use **Roboto 600 15px/20px** (it's Nunito now), padding `13px 7px`, the **caret** after every parent (`eicon-caret-down`, caret span padded `10px 0 10px 10px`), and the **12px × 1px `#7A7A7A30` divider** between items. The nav block is ~575px wide and centred; items are currently spread too far apart.
