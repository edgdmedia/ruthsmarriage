## Contact (biggest; fix first)
`src/pages/contact/index.astro`:
1. **Icons are wrong glyphs.** The envelope and all five social SVGs are hand-written paths that don't draw envelope/Facebook/Twitter/Instagram/YouTube/Threads. Use the components in `src/components/icons/` (the same ones the footer uses) and the Font Awesome `far-envelope` at **50px `#BF1E72`, no circle border** (live has no frame on it).
2. **`flex: 0 0 560px` breaks both narrow layouts.** @1024 it overrides `width: 445px`, so the cards wrap onto two rows (+116). @390 the row is a column, so the 560px basis becomes a 560px *height* (+645). Use `flex: 0 0 auto` with the width per breakpoint, and the heights from the map: 212 @1440, 236 @1024, **Email 236 / Social 139 @390** (auto height there, not min-height 236).
3. **The 70px top/bottom spacing (50 @390) must be section padding**, not margin on `.contact-row`. The comparer measures the section box, hence 212 vs 352 and Δy +70.
4. **Email links**: no underline (live has none). Keep the `mailto:` hrefs.
5. **YouTube**: `youtubeUrl` defaults to `"#"`, so the icon always shows. The map says to **hide** an icon whose settings URL is empty (YouTube until G3). Same for every icon: drop the `|| "#"` fallbacks.
6. Read the addresses from settings `contact_emails`, not hard-coded (map §2).
